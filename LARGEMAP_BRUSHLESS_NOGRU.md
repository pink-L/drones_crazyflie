# largemap_brushless_noGRU

The `OmniDrones` submodule commit records the frozen U153 → V77 brushless large-map implementation. Its source matches the experiment runtime, rather than the previous development worktree.

See [the version manifest and validation instructions](OmniDrones/experiments/largemap_brushless_noGRU/README.md). The selected baseline is U153; V77 is the latest continuation endpoint and showed regression in the recorded evaluation. Models and datasets remain external and are identified in the inner version package.

Both repositories use the local branch/tag `largemap_brushless_noGRU`. No remote push is implied. The original worktree and all historical experiment artifacts remain intact.
